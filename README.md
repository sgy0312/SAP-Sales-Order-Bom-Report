# SAP-Sales-Order-Bom-Report

销售订单 BOM 批量查询报表。

- **程序名**：ZPPR024
- **REPORT 对象**：`zppr024`
- **模块**：PP（生产计划）
- **源码位置**：`src/zppr024.abap`

## 功能说明

按工厂、物料、销售订单等条件批量查询销售订单物料清单（BOM）信息，通过函数 `CS_BOM_EXPL_KND_V1` 完成 BOM 展开，并以 ALV 展示母件与组件的对应关系（支持多层展开）。

## 选择屏幕参数

| 参数 | 说明 |
|------|------|
| `S_WERKS` | 工厂（必填） |
| `S_MATNR` | 物料编码 |
| `S_STLAL` | 物料备选清单（默认 `1`） |
| `P_STLAN` | 物料用途（默认 `1`） |
| `P_DATUV` | 有效开始日期（默认当前日期） |
| `P_C1` | 是否多层展开（复选框，默认勾选） |

## 报表输出说明

ALV 输出字段包括：工厂、母件编码、BOM 基本数量、母件物料单位、母件描述、BOM 用途、物料清单类别、有效日期、项目类别、行项目号、组件物料、组件描述、组件数量、组件单位、行项目文本、仓储地点、成本核算相关、销售订单、销售订单项目等。

## 运行前提

- 销售订单 BOM（`KDST` 表）已维护
- 具备所选工厂的权限（程序内置工厂权限校验 `C_FVER_WRK`）

## 部署步骤

1. 使用事务码 **SE38** 创建程序，将 `src/zppr024.abap` 源码粘贴保存并激活
2. 直接运行或通过 SE93 创建事务代码调用
3. 输入工厂、物料等条件后执行查询
